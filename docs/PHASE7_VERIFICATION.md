# Phase VII verification

## Boundary and provenance checks

The Phase VII runner uses checksum-verified prepared inputs and exact saved Phase IV split files. It fits new fold-local pipelines only on Phase IV development rows. No Phase IV held-out values are loaded for new comparisons, and no original source, prepared file, Phase IV model, selected threshold or historical test result is written. The independent test verifies heart/stroke partition coverage and diabetes predictor-profile group separation. The saved output manifest includes the three raw source SHA-256s, split SHA-256s, seed, library versions and SHA-256s for every derived Phase VII artifact.
